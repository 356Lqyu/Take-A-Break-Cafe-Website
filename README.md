# Take A Break Cafe

A cafe website project that provides customers with an interactive online experience to explore the cafe, browse food and beverage menus, discover promotions, and access customer support.

## Project Overview

Take A Break Cafe is a web-based cafe platform developed using HTML, CSS, and JavaScript. The website showcases the cafe's products and services through a user-friendly interface with multiple pages and interactive features.

The project aims to improve the customer experience by making cafe information, menu items, and promotional content accessible online.

## Features

- **Homepage** – Cafe introduction, featured content, and navigation.
- **Food & Beverage Menu** – Browse different food and drink categories.
- **Shopping Cart** – View and manage selected items.
- **Member Registration & Login** – User registration and login interfaces.
- **Promotions** – Explore featured products and promotional offers.
- **About Us** – Learn about the cafe, its mission, and its vision.
- **Contact Us** – Access cafe contact information.
- **FAQ** – Find answers to frequently asked questions.
- **Customer Service Chatbot** – Interactive chatbot with predefined responses to common customer questions.
- **Find Us** – Access cafe location and social media information.
- **Customer Reviews** – View the cafe's review page.

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Edge, or Safari)
- A code editor such as Visual Studio Code
- Optional: Visual Studio Code Live Server extension

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/356Lqyu/Take-A-Break-Cafe-Website.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Take-A-Break-Cafe-Website
   ```

3. Open the project in Visual Studio Code.

4. Run the website:
   - Open `homepage/homepage.html` directly in your browser, or
   - Use the Live Server extension to launch the website locally.

## 💻 Usage

1. Open the homepage.
2. Navigate through the menu to explore food and beverage categories.
